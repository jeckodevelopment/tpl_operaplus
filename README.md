# Opera+ — Template Joomla 6

Repository ufficiale per il versionamento del template Opera+.

## Stato

Versione di riferimento: **1.10.0** (28 ottobre 2026).

Il pacchetto ZIP installabile è stato consegnato nella conversazione ChatGPT relativa allo sviluppo Opera+. Il caricamento del sorgente completo in questa repository è ancora da completare: questo README iniziale non rappresenta una release pubblicata o sincronizzata.

## Direzione grafica

Riferimenti: https://opera.plus e https://opera.plus/corsi/. Palette bordeaux, antracite e avorio; titoli editoriali Georgia e testi Manrope.

## Regole di manutenzione

Ogni modifica alle classi CSS deve aggiornare sia `GUIDA_STILI.md` sia la documentazione integrata nelle opzioni dello stile Joomla. Consegnare sempre un pacchetto ZIP installabile e verificare il manifest XML e la sintassi PHP.
