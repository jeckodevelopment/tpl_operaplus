# Guida redattore — Magazine (1.28.0)

## Scrivere e pubblicare
1. Creare articolo Joomla nella categoria editoriale pertinente, con titolo chiaro, alias, lingua e stato coerenti con il flusso redazionale. Scegliere il layout Magazine articolo, approfondimento, intervista o recensione, se disponibile nelle opzioni.
2. Inserire immagine intro e immagine completa con testo alternativo significativo; non inserire il titolo H1 nel corpo. Preferire immagini leggere e di dimensioni appropriate, con diritti e crediti verificati. Le foto sono ritagliate nei box, non alterate nel file originale.
3. Scrivere una descrizione SEO sintetica nel campo nativo dell'articolo; il template usa i metadati Joomla e l'immagine completa per la condivisione social, con fallback. Non ripetere il titolo nel primo paragrafo.
4. Usare H2/H3 per strutturare il contenuto, link descrittivi, tabelle brevi e didascalie. Verificare anteprima su mobile prima di pubblicare.

## Modelli e formati
Dal pulsante Opera+ in TinyMCE scegliere Articolo, Intervista, Recensione, Approfondimento, Dossier o Notizia. Il modello inserisce HTML modificabile nel punto di inserimento o nella selezione: non selezionare testo da conservare. Sostituire ogni segnaposto. Se il pulsante o gli stili non sono disponibili, rivolgersi all'amministratore per il set TinyMCE.

- op-editorial-lead: paragrafo introduttivo.
- op-interview-question: domanda.
- op-interview-answer: risposta.

Applicare i formati tramite menu Stili/Formats, rimuovere il formato precedente prima di cambiarlo. Usare le citazioni native dell'editor per citazioni reali, non per enfasi. Per il longform usare il pagebreak/indice Joomla ove pertinente. Il tempo lettura è calcolato dal template, non scritto a mano.

## Recensioni, Atlas e autore
Compilare i campi spettacolo facoltativi (opera, compositore, teatro, città, data, stagione, direzione musicale, regia, orchestra, coro, cast e crediti). Data recita ISO AAAA-MM-GG, distinta dalla data di pubblicazione. Lasciare vuoto ciò che non è noto. Collegare le entità Atlas nel campo atlas-entities; scegliere eventualmente atlas-primary fra quelle associate. Non inserire URL manuali nei campi ID. Il box contestuale non appare se manca un'associazione valida. Il profilo autore usa un contatto pubblico collegato all'utente: aggiornare la bio pubblica secondo le procedure redazionali, non pubblicare recapiti privati.

## Prima di pubblicare
Verificare titolo, descrizione, foto, crediti, gerarchia H2/H3, link, data, lingua, ACL, layout e resa su mobile. Controllare che l'articolo sia collegato alla sezione prevista: i moduli selezionano articoli con i filtri Joomla, non duplicano contenuti. Segnalare anomalie all'amministratore, senza intervenire sui file template o modificare i permessi.
