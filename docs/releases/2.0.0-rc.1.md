# Opera+ Template 2.0.0-rc.1 — candidata per staging

Candidata tecnica; non è la versione stabile, non è autorizzata per il sito di produzione. Richiede Joomla 6 e Opera+ Extensions 1.0.0 per i moduli editoriali e TinyMCE. Il pacchetto non modifica dati editoriali, assegnazioni menu o stili preesistenti.

## Controlli di pubblicazione RC
- CI qualità/browser e Joomla reale sul medesimo commit, installazione nuova, aggiornamento da 1.21.0 e 1.29.0.
- ZIP installabile riproducibile, SHA-256, nessun tool di sviluppo nel document root.
- Prerelease GitHub v2.0.0-rc.1, non latest; niente deploy.
- Feed stabile intenzionalmente vuoto; l'RC si installa manualmente.
